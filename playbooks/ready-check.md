# Playbook: Ready Check

Read: [`standards/lifecycle.md`](../standards/lifecycle.md#ready-for-dev-checklist), [`standards/story.md`](../standards/story.md)

## Steps

1. Fetch the Story (or Task) live.
2. Run the Ready for Dev checklist from `standards/lifecycle.md`.
3. Output pass/fail per item and exactly what is missing. Example: *"No test cases attached; AC4 has an open question."*
